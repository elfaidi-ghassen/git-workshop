## What we cover

<CardGrid stagger>
	<Card title="1. Git Fundamentals" icon="seti:git">
		How Git actually works under the hood: commits, staging, branches,
		merging (fast-forward, three-way), handling conflicts, and
		best practices for writing clean commits. Taught with a **unique and fun,
		analogy-based approach** so the concepts stick.
	</Card>

	<Card title="2. GitHub Workflow" icon="github">
		Setting up **SSH**, cloning, forking, contributing to open source,
		remote tracking branches, pull / push, and pull requests. Plus the
		most important part: a **practical day-to-day workflow** you can use
		in real projects. We also cover Github projects and issues, and how to use them to manage your work.
	</Card>

	<Card title="3. Advanced Git" icon="code-branch">
		Rebase, cherry-picking, fixing mistakes and using Bisect to find bugs.
    Best practices drawn from real experience, plus one **final challenge:** how to resolve
		**database migration conflicts** when working in a team.
	</Card>

	<Card title="4. Security in Git" icon="padlock">
		Security concepts applied to Git: asymmetric cryptography explained
		simply, **signed commits**, and why they matter for trust and
		integrity in collaborative work.
	</Card>
</CardGrid>
